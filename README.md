# Finance Tools

Interactive finance tools I built with AI agents for a consumer goods company. All data is anonymized ("Sample Co.").

**Live site:** https://basav16.github.io/finance-tools/

| Tool | What it does |
| --- | --- |
| [FP&A Dashboard](https://basav16.github.io/finance-tools/fpa-dashboard.html) | Three-statement model with plan vs actuals, channel P&L, covenant and runway tracking, and what-if scenarios |
| [Inventory Open-to-Buy](https://basav16.github.io/finance-tools/inventory-open-to-buy.html) | SKU-level inventory plan by channel and warehouse, with weeks of supply, aging, buy plan and pricing ROI |
| [PO Tracker](https://basav16.github.io/finance-tools/po-tracker.html) | Purchase orders matched to receipts and bills, landed cost and freight checks, and credit memos |
